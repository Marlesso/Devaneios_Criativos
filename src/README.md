# Devaneios Criativos

Um depósito de conteúdo criativo sobre livros, personagens, culturas, rituais e criaturas. A interface foi construída com React, TypeScript e Vite.

## Executar localmente

Instale as dependências e inicie o servidor de desenvolvimento na pasta deste projeto:

```bash
npm install
npm run dev
```

## Outros comandos

- `npm run build` — verifica os tipos e gera a versão de produção em `dist/`.
- `npm run lint` — executa o ESLint.
- `npm run preview` — pré-visualiza a versão de produção.

Os conteúdos exibidos ficam em `src/assets/data.ts`.
